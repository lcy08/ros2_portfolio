## Something I learn from a course:
- ### talker_listener
  ---
  _(publisher and subscription)_

  _(launch files and parameter)_

  _(testing)_

  run the launch files

  `ros2 launch talker_listener talker_listener.launch.py`

- ### custom_interfaces
  ---
  used as interface for add_integers

- ### add_integers
  ---
  _(service and client)_

  run the service node by

  `ros2 run add_integers addition_service`

  and the client node need two argument for the addition

  `ros2 run add_integers addition client a b`
  
  with a and b accepting integer value
